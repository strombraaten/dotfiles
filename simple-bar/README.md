# Simple-bar Configuration

This directory contains configuration and management information for simple-bar, a customizable status bar widget for Übersicht.

## Installation Location

Simple-bar is installed at: `~/Library/Application Support/Übersicht/widgets/simple-bar/`

This is the standard Übersicht widgets directory where simple-bar must reside to function properly.

## Configuration

Simple-bar can be configured through its built-in settings panel. After starting Übersicht:

1. Right-click on the simple-bar widget
2. Select "Open simple-bar settings"
3. Configure widgets, themes, and preferences

## Key Features

- **Window Manager Integration**: Works with yabai (and AeroSpace)
- **System Monitoring**: CPU, memory, network, battery
- **Media Integration**: Spotify, iTunes, YouTube Music
- **Custom Widgets**: Weather, crypto, stocks, GitHub notifications
- **Themes**: Multiple built-in themes with customization options

## Recommended Settings

For optimal integration with yabai:

1. **Spaces Widget**: Enable to show yabai spaces
2. **Process Widget**: Enable to show running applications
3. **System Stats**: Enable battery, network, CPU widgets
4. **Theme**: Choose a theme that matches your macOS appearance

## Widget Location

The simple-bar widget files are located at:
- Main widget: `~/Library/Application Support/Übersicht/widgets/simple-bar/`
- Settings: Accessible through the widget's right-click menu

## Troubleshooting

If simple-bar doesn't appear:
1. Ensure Übersicht is running
2. Check that yabai is configured correctly
3. Refresh Übersicht widgets (Command+R)
4. Check widget visibility in Übersicht preferences

## Integration with yabai

Simple-bar automatically detects yabai and provides:
- Space switching controls
- Window focus indicators  
- Tiling layout information
- Application icons and titles
